# ShareIt

ShareIt — backend-сервис для аренды и обмена вещами между пользователями.

Проект моделирует реальную платформу, где пользователи могут делиться своими вещами, бронировать предметы и управлять заявками на аренду.

---

## Архитектура

Приложение построено как REST API с разделением на слои:

- Controller — обработка HTTP-запросов
- Service — бизнес-логика
- Repository — работа с базой данных

---

## Функциональность

### Пользователи
- регистрация пользователей
- получение информации о пользователе

### Вещи
- добавление предметов для аренды
- редактирование и удаление
- поиск по названию и описанию
- комментарии к вещам

### Бронирование
- создание заявки на аренду
- подтверждение или отклонение брони
- управление доступностью вещей
- история бронирований
